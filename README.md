# linux-zabbix-monitoring-lab
Linux infrastructure monitoring lab using Zabbix, Docker and Ubuntu Server.

## Overview

This project demonstrates the deployment and configuration of an infrastructure monitoring environment using Zabbix and Ubuntu Server.

The goal of the project is to monitor system resources, network availability and service status in a small Linux infrastructure.

## Technologies

- Ubuntu Server
- Zabbix
- Docker
- Docker Compose
- VirtualBox
- Linux CLI
